# 📍 Plateforme Intelligente de Signalement Urbain — Balligh+

> **Cas des Communes Algériennes**

## À propos du projet

**Balligh+** est une plateforme intelligente développée pour faciliter le signalement des problèmes urbains dans les communes algériennes. Elle permet aux citoyens de rapporter rapidement et efficacement les problèmes d'infrastructure, de salubrité ou d'équipements publics.
